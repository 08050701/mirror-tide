# Mirror Tide / 水鏡・深潛

獨立的 WebGL2 互動藝術作品，不依賴 p5.js。這是可公開分享的安全試玩版：自動 3D 鏡頭、持續語音聆聽、GAS／OpenAI 語意問答，以及依真實天氣改變的水體氛圍。

## AI 問答與資料使用

公開版透過 GAS 呼叫 OpenAI，實際回答問題並選擇水色與動態。沒有本機預設回覆；連線失敗會明確顯示。

- OpenAI 金鑰只存在 GAS Script Properties，不放在網頁。
- 辨識文字與最近兩輪對話傳至 GAS／OpenAI；頁面不保存對話紀錄。
- 用戶端隨機識別碼存於 Local Storage，用於節流；它不是登入憑證。
- GAS 每用戶端每分鐘 6 次、全站每日 250 次上限。公開端點可被其他人呼叫並消耗此額度，並非完整防濫用服務。
- Web Speech 可能由瀏覽器供應商在線處理語音；Web Audio 頻譜分析在本機執行。
- 控制頁提供「輸入問題測試 AI」和真實連線狀態。

## 聲音如何成為水

- 24 個對數頻段形成多層「水紋譜」，每一層再由即時時間波形扭動。
- 低頻推動鏡頭與深水體積，中頻拉出空間中的半透明飄帶，高頻細化纖維光。
- 頻譜峰值會形成漂移的偏心光環；聲音突變會短暫浮出受克拉尼節線啟發的水膜花紋。
- 聆聽、思考、回答不是切換畫面，而是以不同時間常數互相暈染，避免突兀跳接。
- 鏡頭持續進行慢速 dolly、orbit 與 bank，不依賴展場滑鼠也能感到縱深。

## 麥克風權限

第一次開正式 GitHub Pages 網址時，使用者會看到隱私說明與「允許麥克風並進入展覽」。按鈕才會呼叫瀏覽器的麥克風權限；之後同一個 HTTPS 網址若已被瀏覽器設為允許，重新整理會直接進入聆聽。隱私模式、清除網站資料，或把瀏覽器設為「每次詢問」仍會再次出現系統權限視窗，網頁無法繞過這項安全設定。

## 天氣映射

- 降雨：畫面出現分散、不同生命週期的小水圈。
- 風速：增加鏡頭漂移、長波速度與絲流偏移。
- 雲量與濕度：提高深處霧化與光線擴散。
- 日夜：夜間水色會逐漸轉冷，不會瞬間切換。

預設使用台北座標。可用 `?lat=緯度&lon=經度` 指定展場位置；`?weather=rain`、`?weather=storm`、`?weather=clear` 可排練不同天氣。天氣每十分鐘更新一次，來源為 [Open-Meteo](https://open-meteo.com/)。

## GitHub Pages

將此資料夾內容放在公開儲存庫的 `main` 分支根目錄，在 **Settings → Pages** 選擇 **Deploy from a branch → main → /(root)**。`.nojekyll` 已包含在專案內。

工作人員需要控制介面時使用 `?control=1`；沒有麥克風的排練模式使用 `?demo=1`。可組合 `?demo=1&weather=storm` 檢查最完整的聲音與天氣層次。
